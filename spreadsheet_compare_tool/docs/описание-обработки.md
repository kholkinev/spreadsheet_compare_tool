# Сравнение табличных документов

Внешняя обработка 1С для сравнения двух табличных документов схожей структуры и выявления расхождений. Используется при сверке отчетов (в том числе при переносе остатков) и анализе прайс-листов.

Версия регистрации: `2026.10.26`. Вид: дополнительная обработка, команда открывает управляемую форму `ФормаУпраляемая`.

Разработка ведется в EDT. Исходники: `spreadsheet_compare_tool/src/ExternalDataProcessors/СравнениеТабличныхДокументов`.

## Поддерживаемые форматы

- `*.mxl` — табличный документ 1С
- `*.xls`
- `*.xlsx`

Файлы Excel читаются средствами платформы, установленный MS Excel не требуется. Для книг Excel выбирается лист: список листов заполняется из областей документа, по умолчанию берется первый лист. Смена листа перечитывает соответствующую область.

## Порядок работы

1. Выбрать тип файлов.
2. Указать два файла. Несуществующий или нечитаемый файл приводит к ошибке чтения.
3. Задать диапазон строк и колонок для каждого файла. Если конечные значения выходят за пределы документа, чтение завершается ошибкой.
4. Заполнить выводимые колонки (кнопка заполнения берет колонки из заданного диапазона). Для колонок можно задать наименование в шапке результата и тип значения. Для чисел лучше указывать тип «Число»: сравнение чисел точнее, чем сравнение числовых строк.
5. В «Сопоставление строк» указать ключевые колонки первого и второго файла. Несколько строк объединяются по «И»: строка считается той же, только если совпали все ключевые поля.
6. В «Сравнение строк» указать колонки, по которым решается, одинаковы строки или отличаются.
7. Задать режим сравнения и оформление, затем выполнить сравнение.
8. Результат можно отфильтровать и сохранить в MXL или XLS.

Настройки формы сохраняются между сеансами.

## Режимы сравнения

### Последовательное

Строки читаются синхронно сверху вниз.

- Совпали ключевые поля — сравниваются поля сравнения, в результат выводится одна строка.
- Ключевые поля не совпали — в результат выводятся две строки: только в первом файле и только во втором.
- Лишняя строка в одном из файлов смещает дальнейшее сопоставление, поэтому одинаковые строки ниже могут быть распознаны неверно.

Подходит, когда порядок строк в файлах совпадает.

### Обычное

- Берется строка первого файла.
- Во втором файле ищется строка с теми же ключевыми полями.
- Если найдена — выполняется сравнение, строка больше не участвует в поиске, в результат выводится одна строка.
- Если не найдена — строка выводится как присутствующая только в первом файле.
- Строки второго файла, не сопоставленные после прохода по первому, выводятся в конце как присутствующие только во втором файле.

## Результат

Строки раскрашиваются по трем случаям. Цвета фона и шрифта задаются отдельно:

| Случай | Реквизиты цвета |
| --- | --- |
| Строки отличаются | `ОтличаютсяЦветФона`, `ОтличаютсяЦветШрифта` |
| Только в первом файле | `ТолькоВФайл1ЦветФона`, `ТолькоВФайл1ЦветШрифта` |
| Только во втором файле | `ТолькоВФайл2ЦветФона`, `ТолькоВФайл2ЦветШрифта` |

Отбор результата:

- показать все;
- показать отличия;
- показать строки только из первого файла;
- показать строки только из второго файла.

Для отличающихся колонок в результате выводятся их имена. Число найденных различий накапливается в `ВсегоРазличий`.

## Настройки сравнения

| Настройка | Поведение |
| --- | --- |
| Обрезать пробелы | Незначащие пробелы в начале и конце ячейки не учитываются в ключевых полях и полях сравнения |
| Не учитывать регистр | Строки сравниваются без учета регистра |
| Не выводить одинаковые строки | Идентичные строки не попадают в результат |
| Выводить расшифровку цветов | В конце результата выводится легенда раскраски |
| Выводить разницу числовых колонок | Для числовых колонок сравнения выводится разность. Колонки должны входить в выводимые и иметь числовой тип |

## Состав обработки

Реквизиты: пути и краткие имена файлов, имена листов, тип файлов, признаки формата, диапазоны строк и колонок, флаги сравнения, цвета оформления, текст состояния, табличные документы исходных файлов и результат.

Табличные части:

- `СопоставлениеСтрок` — ключевые колонки (`Файл1`, `Файл2`)
- `СравнениеСтрок` — сравниваемые колонки
- `ЛистыФайла1`, `ЛистыФайла2` — имена листов книг Excel
- `ВыводимыеКолонкиФайл1`, `ВыводимыеКолонкиФайл2` — наименование, номер колонки, тип значения

Формы:

- `ФормаУпраляемая` — основная форма
- `ФормаВыбораЛиста` — выбор листа

Макет `Макет` используется при выводе шапки, строк, признаков различия и расшифровки цветов.

## Программный интерфейс

Точка входа сравнения — `ВыполнитьСравнение` модуля объекта.

Последовательность:

1. Проверка заполнения (`ПроверитьКорректностьЗаполнения`).
2. Чтение диапазонов в таблицы (`ЗаполнитьТаблицуMXL`).
3. Преобразование числовых строк (`ПреобразоватьЧисловыеСтроки`).
4. Проверка, можно ли выводить разницу (`ПроверитьВозможностьВыводаРазницы`).
5. При необходимости — регистронезависимые колонки (`ДобавитьРегистронезависимыеКолонки`).
6. Сравнение: `СравнитьТаблицыПоследовательно` или `СравнитьТаблицы`.
7. Результат помещается в реквизит `Результат`.

Регистрация в подсистеме дополнительных отчетов и обработок — `СведенияОВнешнейОбработке`. Безопасный режим отключен.

Чтение файла на форме: файл помещается во временное хранилище, записывается во временный файл и читается в `ТабличныйДокумент`. Для Excel дополнительно выделяется область выбранного листа.

## Ограничения

- Сравниваются два документа за один запуск.
- Сопоставление строится по явно заданным колонкам, а не по всей строке.
- В последовательном режиме вставка или удаление строки смещает сравнение ниже по файлу.
- Разница выводится только для числовых колонок, которые участвуют и в сравнении, и в выводе.
- Пустая первая таблица прерывает сравнение без формирования результата.
