# Обработка «Сравнение табличных документов»

## 1. Назначение

Внешняя обработка (`ВнешняяОбработка.СравнениеТабличныхДокументов`) сравнивает два табличных документа форматов `*.mxl`, `*.xls`, `*.xlsx` и формирует табличный документ-отчёт с подсветкой различий.

Для каждой строки первого файла обработка ищет соответствующую строку во втором по заданным колонкам сопоставления и сравнивает значения в колонках сравнения. Результат помечается одним из четырёх признаков: строки совпадают, строки отличаются, строка есть только в первом файле, строка есть только во втором файле.

Регистрация в БСП: `СведенияОВнешнейОбработке()` — вид «Дополнительная обработка», одна команда открытия формы, `БезопасныйРежим = Ложь`.

## 2. Как пользоваться

1. Открыть обработку, выбрать **тип файлов** (`*.mxl`, `*.xls`, `*.xlsx`).
2. Указать **Файл1** и **Файл2**. Файл читается сразу: для `xls/xlsx` предлагается лист, границы данных определяются автоматически.
3. Проверить **начальные и конечные строки/колонки** для каждого файла — это прямоугольник данных.
4. Заполнить **выводимые колонки** (кнопки «Заполнить выводимые колонки» у каждой таблицы): наименование берётся из строки заголовка, тип значения определяется автоматически. При необходимости переименовать колонки и поправить тип (`Текст`/`Число`).
5. Заполнить **сопоставление строк** — пары колонок, по которым строки считаются одной и той же строкой.
6. Заполнить **сравнение строк** — пары колонок, значения которых сравниваются.
7. Отметить флаги: «последовательное сравнение», «обрезать пробелы», «не учитывать регистр», «не выводить одинаковые строки», «выводить разницу числовых колонок сравнения», «выводить расшифровку цветов». При необходимости настроить цвета.
8. Нажать **«Сравнить»** — открывается вкладка «Результат».
9. Фильтровать результат кнопками «Показать все / отличия / присутствующие в первом файле / присутствующие во втором файле».

Настройки табличных частей и тип файлов сохраняются в настройках формы.

## 3. Настройки (реквизиты обработки)

| Реквизит | Назначение |
|---|---|
| `ТипФайлов` | Фильтр выбора файла: `*.mxl`, `*.xls`, `*.xlsx`; определяет флаги `ЭтоМXL`/`ЭтоХLS`/`ЭтоХLSX` |
| `Файл1`, `Файл2` | Полные имена файлов; `ИмяФайла1/2` — краткие имена для шапки отчёта |
| `ИмяЛистаФайла1/2`, `ЛистыФайла1/2` | Выбранный лист и список листов (только для `xls/xlsx`) |
| `Файл1ТабДок`, `Файл2ТабДок` | Прочитанные табличные документы |
| `ФайлNНачальнаяСтрока`, `ФайлNКонечнаяСтрока`, `ФайлNНачальнаяКолонка`, `ФайлNКонечнаяКолонка` | Границы области данных (N = 1, 2) |
| `СопоставлениеСтрок.Файл1/Файл2` | Пары колонок для поиска соответствующей строки |
| `СравнениеСтрок.Файл1/Файл2` | Пары колонок, значения которых сравниваются |
| `ВыводимыеКолонкиФайлN.Наименование/НомерКолонки/ТипЗначения` | Состав и порядок колонок в отчёте |
| `ПоследовательноеСравнение` | Сравнивать строки по порядку, без поиска по сопоставлению |
| `ОбрезатьПробелы` | `СокрЛП` для строковых значений при сравнении |
| `НеУчитыватьРегистр` | Регистронезависимое сравнение (через колонки `<имя>Регистр`) |
| `НеВыводитьОдинаковыеСтроки` | Не выводить совпавшие строки |
| `ВыводитьРазницуЧисловыхКолонокСравнения` | Добавить блок «Разница» (значение1 − значение2) |
| `ВыводитьРасшифровкуЦветов` | Легенда цветов в конце отчёта |
| `ОтличаютсяЦветФона/ЦветШрифта`, `ТолькоВФайл1...`, `ТолькоВФайл2...` | Цвета подсветки; по умолчанию: отличия — красный/белый, только в файле 1 — жёлтый/чёрный, только в файле 2 — бледно-зелёный/чёрный |
| `Результат` | Сформированный табличный документ |

## 4. Как работает сравнение

Обе таблицы читаются построителем запроса по области `R{нач}C{нач}:R{кон}C{кон}` и выгружаются в `ТаблицаЗначений`; имена колонок — из строки заголовка. Затем числовые колонки преобразуются в числа, при `НеУчитыватьРегистр` во второй таблице добавляются колонки `<имя>Регистр` со значением `ВРег`.

- **Обычное сравнение** — для каждой строки первого файла строится отбор по `СопоставлениеСтрок` и вызывается `НайтиСтроки`. Найденная строка (первая) сравнивается по `СравнениеСтрок` и удаляется из второй таблицы; оставшиеся строки выводятся как «только во втором файле».
- **Последовательное сравнение** — строки сопоставляются по номеру; если ключи сопоставления не совпали, выводятся две отдельные строки (только в 1 / только во 2).

Признаки в отчёте: `7` — совпадают, `6` — отличаются, `1` — только в первом, `2` — только во втором. Признак выводится в первую колонку и используется фильтрами и раскраской.

Вывод: области макета `Шапка|*`, `Строка|*`, `Расшифровка`; шапка с именами файлов и фиксацией сверху, подсветка отличающихся колонок, расчёт ширины колонок (до 200 строк, ограничение 50 символов).

## 5. Программный интерфейс (модуль объекта, экспортные методы)

`СведенияОВнешнейОбработке()`, `ВыполнитьСравнение()`, `АвтоЗаполнениеНачальныхКонечныхСтрокКолонок(Режим)`, `ПолучитьСтруктуруКонечныхЗначенийMXL(Режим)`, `АвтоЗаполнениеВыводимыхКолонок(Режим)`, `ЗаполнитьВыводимыеКолонкиMXL(Режим)`, `ОтображениеРезультатаУстановитьОтбор(РежимОтбора)`, `УстановитьИсходнуюШиринуКолонок(ТабДокумент)`, `РаскраситьСтроки(ТабДокумент, СтруктураДокумента)`, `ВывестиРасшифровкуЦветов(ТабДокумент, Макет)`, `ПолучитьЧисло(ЗначениеЯчейки)`, `ПолучитьСтроку(Значение)`, `РазложитьСтрокуВМассивПодстрокЛокальная(Строка, Разделитель, ПропускатьПустыеСтроки)`.

`Режим` = `"1"` / `"2"` — номер файла.

## 6. Ограничения и зоны риска

1. **Разница числовых колонок.** В `ВывестиРазницу` имя колонки формируется как `"К" + Строка.Файл1`, тогда как в `СравнениеСтрок.Файл1` форма записывает наименование колонки из заголовка. При непустом заголовке значение не находится и разница считается от нуля.
2. **Дубли по ключу сопоставления.** В обычном сравнении берётся только первая найденная строка (`Строки2[0]`) и она удаляется из второй таблицы, поэтому при неуникальных ключах результат зависит от порядка строк.
3. **Мутация второй таблицы.** `СравнитьТаблицы` объявлена с `Знач`, но удаляет строки из переданной `Таблица2`.
4. **Последовательное сравнение без шапки.** Вызов `ВывестиШапку` закомментирован, `СтруктураДокумента` остаётся пустой — раскраска по номерам колонок не применяется, блок «Разница» не выводится.
5. **Строка заголовка = первая строка данных.** Область читается начиная с `ФайлNНачальнаяСтрока`, эта же строка используется как заголовок; отдельного «строки заголовка» нет.
6. **`ПолучитьЧисло` возвращает 0 при ошибке преобразования** — неотличимо от реального нуля.
7. **Мёртвый и отладочный код:** `ЗаполнитьТаблицуMXL` переприсваивает параметр `Таблица` (заготовка колонок `К<i>` отбрасывается), читает `Область("R1C2")` в неиспользуемую переменную, содержит большие закомментированные блоки; в форме есть неиспользуемые `ПрочитатьТабДок`, `ДействияПослеВыбораЛиста`, пустые обработчики; форма `Форма` (обычная) пустая; страница справки — заготовка.
8. **Проверка настроек неполная.** В `ПроверитьКорректностьЗаполнения` закомментированы проверки диапазонов колонок и вхождения колонок сопоставления/сравнения в выводимые.
9. **Фильтр по признаку** перебирает строки начиная с 4-й и останавливается на первом пустом признаке, поэтому строки-разделители прерывают фильтрацию.
